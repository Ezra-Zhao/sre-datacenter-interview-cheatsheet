# SRE / Data Center Interview Cheatsheet

## 中文

SRE 与数据中心运维面试速查表，覆盖 Linux、网络、机房运维、Kubernetes、on-call 事件响应、Prometheus 监控与 10 个线上真实排障场景。
每道题采用"问题 → 简短标准答案 → 追问提示"格式，适合面试前快速过一遍，也适合日常查漏补缺。
完整内容为西班牙语与巴西葡萄牙语两个独立版本，由母语技术写作习惯写就，面向拉美与伊比利亚半岛的开发者社区。

## English

A quick-reference interview guide for SRE and data center operations: Linux, networking, facility ops, Kubernetes, on-call incident response, Prometheus monitoring, plus 10 real-world production troubleshooting scenarios.
Each item follows a "question → short reference answer → follow-up prompts" format — ideal for last-minute prep or daily review.
Full content is published as two standalone editions in Spanish and Brazilian Portuguese, written natively for Latin American and Iberian developer communities.
